# Signally — Crosswalk Icon System v3

원본 디자인 보드의 **01 Crosswalk** 심볼에 노랑 포인트를 적용하고, 사람+횡단보도 픽토그램을 활용한 지도 마커를 벡터로 재구성한 세트입니다. 모든 `.svg`는 편집 가능한 실제 SVG 요소로 작성했습니다. 스크린샷을 SVG 파일 안에 단순 삽입한 파일은 없습니다.

## 구성

- `brand/`: 앱 아이콘(다크/라이트), 투명 심볼, 반전 심볼, SVG 워드마크, 파비콘
- `signals/`: 보행/정지/미확인 기본 픽토그램, 흰색 마커용 픽토그램
- `map/`: 신호 핀 3색 × 기본/선택, 축소 지도용 3색 핀, 지도 컨트롤 5종, 내 위치
- `examples/`: 타이머를 내장한 **디자인 미리보기용** 마커. 숫자는 가상의 DEMO 값으로 실제 신호가 아닙니다.

## 빠른 적용

1. `public/icons/` 아래에 `brand`, `signals`, `map` 폴더를 복사하세요.
2. 상단 로고는 `/icons/brand/app-icon-dark.svg` 또는 `/icons/brand/crosswalk-symbol.svg`를 사용하세요.
3. 지도 기본 마커는 `/icons/map/signal-pin-green-base.svg`처럼 **-base**를 사용하고, 오른쪽 빈 영역에 React/CSS로 실시간 `remainingSeconds`를 겹쳐 그리세요.
4. 확대 축소 지도에서는 `/icons/map/signal-pin-*-compact.svg`를 사용하세요.
5. DEMO/실측/LIVE 미검증 데이터 출처 표시는 기존 시그널리 정책대로 유지하세요.

`examples/*-demo.svg`의 정적인 '18초', '12초'는 실제 마커에 사용하지 마세요. SVG 내부 텍스트를 매초 바꿔 파일 재다운로드하는 방식 대신 HTML 오버레이나 React 마커로 숫자만 갱신하는 방식을 권장합니다.

## 크기 가이드

| 요소 | 권장 렌더 크기 |
|---|---|
| 앱 아이콘 | 48×48, 96×96 |
| 헤더 브랜드 심볼 | 32×32 |
| 신호 지도 핀 | 122–156px 너비 (260:105 비율) |
| 작은 신호 핀 | 약 32×36 |
| 지도 컨트롤 | 44×44 터치 타깃 |
| 현재 위치 | 28–36px |

## 컬러

- 브랜드 딥 그린: `#064E3B`
- 상태 그린: `#076747`
- 상태 레드: `#C72E42`
- 미확인 그레이: `#828C91`
- 브랜드 민트: `#8EE4BA`
- 횡단보도 포인트 옐로: `#FFC433`

**참고:** 마커 SVG의 짙은 배경 색은 상태별 표현이고, 브랜드 로고의 노란색 포인트는 장식입니다. 신호 마커 색이 시뮬레이션 값이라면 DEMO임을 계속 표시해야 합니다. `brand/wordmark.svg` 텍스트는 시스템 폰트를 사용하며 서체는 렌더링 환경에 따라 달라질 수 있습니다.
